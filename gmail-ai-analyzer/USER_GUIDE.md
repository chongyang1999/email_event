## 基础使用

### 分析单封邮件

#### 场景：快速了解邮件内容

**步骤**：

1. **打开Gmail**
   - 访问 https://mail.google.com
   - 点击打开任意一封邮件

2. **启动AI分析**
   - 点击Chrome工具栏的扩展图标
   - 在弹出窗口点击 **"✨ 分析当前邮件"**

3. **等待分析**
   - 状态栏会显示进度
   - 通常需要2-5秒

4. **查看结果**
   - 邮件摘要
   - 关键人物
   - 重要时间点
   - 行动项
   - 优先级评估

**示例输出**：

```
📧 邮件主题：Q1季度业绩报告会议通知
📅 时间：2024-11-15 09:30:00
👤 发件人：张三 <zhangsan@company.com>

邮件摘要：
通知下周一上午10点召开Q1季度业绩报告会议，需要准备本部门的
业绩数据和PPT，会议预计持续2小时。

关键人物：
- 张三（发件人，项目经理）
- 李四（财务总监）
- 王五（销售总监）

重要时间点：
- 会议时间：2024-11-18 10:00 AM
- 材料提交截止：2024-11-17 5:00 PM

行动项：
1. 准备本部门Q1业绩数据
2. 制作PPT（不超过10页）
3. 11月17日下午5点前发送给张三

优先级评估：高
- 涉及高层会议
- 有明确截止时间
- 需要提前准备材料
```

### 复制分析结果

分析完成后：

1. 点击 **"📋 复制结果"** 按钮
2. 结果已复制到剪贴板
3. 可以粘贴到：
   - 笔记应用（Notion、Obsidian等）
   - 任务管理工具（Todoist、Trello等）
   - 文档编辑器

### 重新分析

如果对结果不满意：

1. 点击 **"🔄 重新分析"** 按钮
2. 可以修改提示词后重新分析
3. 尝试更换AI模型

## 高级功能

### 自定义提示词

#### 为什么要自定义？

默认提示词是通用的，但你可能有特定需求：
- 只关注特定信息
- 特殊的输出格式
- 针对特定类型邮件

#### 如何自定义？

**示例1：极简模式**

```
用3个要点总结这封邮件，每个要点不超过15个字。
```

**示例2：任务提取模式**

```
请只列出这封邮件中：
1. 我需要做的事情
2. 每件事的截止时间
3. 优先级排序

以清单格式输出。
```

**示例3：人际关系模式**

```
分析这封邮件的人际关系：
1. 发件人对我的态度（正式/友好/冷淡）
2. 邮件的真实意图
3. 是否有隐含的期望或要求
4. 建议的回复策略
```

**示例4：商务邮件模式**

```
商务邮件分析：
1. 客户的核心诉求
2. 潜在的商机或风险
3. 需要跟进的具体事项
4. 建议的回复时间（紧急/一般/可延后）
```

**示例5：技术邮件模式**

```
技术邮件解析：
1. 技术问题描述
2. 关键技术术语解释
3. 需要的技术准备
4. 预计解决难度（简单/中等/困难）
```

### 模型选择策略

| 模型 | 速度 | 质量 | 适用场景 |
|------|------|------|----------|
| **Gemini 2.5 Flash** | ⚡⚡⚡ | ⭐⭐⭐⭐ | 日常邮件，推荐 |
| **Gemini 2.5 Flash Preview** | ⚡⚡⚡ | ⭐⭐⭐⭐⭐ | 体验最新功能 |
| **Gemini 1.5 Flash** | ⚡⚡⚡ | ⭐⭐⭐ | 快速浏览 |
| **Gemini 1.5 Pro** | ⚡⚡ | ⭐⭐⭐⭐⭐ | 复杂邮件，深度分析 |
| **Gemini 1.0 Pro** | ⚡⚡ | ⭐⭐⭐ | 稳定性优先 |

**建议**：
- 90%的情况：使用 **Gemini 2.5 Flash**
- 长邮件或复杂内容：使用 **Gemini 1.5 Pro**
- 测试新功能：使用 **Preview版本**

## 使用技巧

### 技巧1：快速处理大量邮件

**场景**：早上打开邮箱有50封未读邮件

**策略**：
1. 先浏览邮件标题
2. 对重要邮件使用AI分析
3. 根据分析结果决定优先级
4. 复制分析结果到任务清单

**时间节省**：原本需要30分钟，现在只需10分钟

### 技巧2：邮件归档助手

**场景**：需要整理项目相关邮件

**策略**：
1. 分析每封项目邮件
2. 复制关键信息
3. 粘贴到项目文档
4. 建立邮件内容索引

**提示词示例**：
```
提取以下信息：
- 项目名称
- 相关人员
- 决策内容
- 下一步行动
按表格格式输出
```

### 技巧3：会议准备

**场景**：明天有重要会议，需要回顾相关邮件

**策略**：
1. 找出所有会议相关邮件
2. 逐个分析
3. 汇总关键信息
4. 准备会议发言要点

**提示词示例**：
```
这是一封会议相关邮件，请提取：
1. 会议议题
2. 我的角色和期望
3. 需要准备的材料
4. 可能的提问方向
```

### 技巧4：客户沟通记录

**场景**：管理客户邮件往来

**策略**：
1. 分析客户邮件
2. 记录客户需求变化
3. 追踪承诺和交付
4. 识别潜在问题

**提示词示例**：
```
客户沟通记录：
1. 客户新增需求
2. 客户满意度信号（正面/负面）
3. 需要升级处理的问题
4. 下次沟通重点
```

### 技巧5：语言学习

**场景**：收到英文邮件，想学习表达方式

**提示词示例**：
```
分析这封英文邮件：
1. 中文翻译
2. 关键商务英语短语（列出5个）
3. 邮件的语气和正式程度
4. 如何用英语回复（给出模板）
```

## 实际应用场景

### 场景1：职场新人

**痛点**：
- 不熟悉公司邮件文化
- 难以判断邮件重要性
- 不知如何回复正式邮件

**解决方案**：
1. 用AI分析每封重要邮件
2. 学习邮件的隐含信息
3. 参考AI建议制定回复策略

**提示词**：
```
这是一封来自上级的邮件，帮我分析：
1. 真实意图（指令/建议/通知）
2. 期望的回应方式
3. 潜在的注意事项
4. 专业回复的要点
```

### 场景2：项目经理

**痛点**：
- 每天上百封项目邮件
- 需要快速提取关键信息
- 跟踪多个项目进度

**解决方案**：
1. 批量分析项目邮件
2. 提取任务和时间节点
3. 自动生成项目进度报告

**提示词**：
```
项目管理视角分析：
1. 项目里程碑更新
2. 风险和阻塞因素
3. 资源需求变化
4. 需要向上汇报的内容
```

### 场景3：销售人员

**痛点**：
- 客户意向难以判断
- 跟进时机不好把握
- 需要快速响应客户

**解决方案**：
1. 分析客户邮件情绪
2. 识别购买信号
3. 制定跟进策略

**提示词**：
```
销售机会分析：
1. 客户意向强度（1-10分）
2. 决策阶段（了解/考虑/决策）
3. 关键障碍
4. 建议的跟进话术
5. 最佳跟进时间
```

### 场景4：学术研究

**痛点**：
- 收到大量学术邮件
- 需要筛选相关信息
- 整理文献和会议通知

**解决方案**：
1. 分析会议通知重要性
2. 提取论文投稿截止日期
3. 整理审稿意见要点

**提示词**：
```
学术邮件处理：
1. 会议/期刊质量评估
2. 投稿截止时间
3. 审稿意见摘要
4. 需要的修改工作量（高/中/低）
```

### 场景5：客户服务

**痛点**：
- 客户投诉需要快速响应
- 难以识别情绪严重程度
- 需要标准化回复模板

**解决方案**：
1. 分析客户情绪
2. 提取核心问题
3. 生成回复要点

**提示词**：
```
客户服务分析：
1. 客户情绪（愤怒/失望/中性/满意）
2. 核心诉求（退款/补偿/解释/道歉）
3. 严重程度（需升级/常规处理/简单回复）
4. 建议回复策略
```

## 最佳实践

### 1. API Key管理

**建议**：
- ✅ 定期检查API使用额度
- ✅ 不要在公共电脑保存API Key
- ✅ 发现异常使用立即撤销Key
- ✅ 为不同设备使用不同Key（如需要）

**检查使用量**：
访问 [Google AI Studio](https://aistudio.google.com) 查看配额

### 2. 提示词优化

**通用原则**：
1. **具体明确**：说清楚要什么信息
2. **结构化输出**：要求用列表、表格等格式
3. **限制长度**：避免AI输出过长
4. **增量优化**：根据结果不断调整

**好的提示词示例**：
```
分析这封邮件，用3个要点总结：
1. [要点1]
2. [要点2]
3. [要点3]
每个要点10-15字。
```

**不好的提示词示例**：
```
帮我看看这封邮件说了什么。
```

### 3. 隐私保护

**注意事项**：
- ⚠️ 敏感邮件谨慎使用（涉及密码、合同等）
- ⚠️ 公司机密信息不要分析
- ⚠️ 个人隐私信息注意保护
- ✅ 查看Gemini API的隐私政策

**建议**：
对于极度敏感邮件，使用传统方式阅读

### 4. 效率最大化

**工作流建议**：

**早晨第一件事**：
1. 打开Gmail
2. 扫描所有未读邮件主题
3. 标记5-10封重要邮件
4. 用AI逐个分析
5. 根据分析结果安排今天工作

**午间休息**：
1. 检查新邮件
2. 快速分析紧急邮件
3. 非紧急邮件稍后处理

**下班前**：
1. 清理收件箱
2. 分析遗漏的重要邮件
3. 准备明天的任务清单

### 5. 团队协作

**场景**：团队多人使用

**建议**：
1. **统一提示词模板**：团队共享优质提示词
2. **建立最佳实践文档**：记录使用技巧
3. **定期分享经验**：团队会议上分享使用心得
4. **创建提示词库**：针对不同场景的模板

## 故障排除

### 问题1：分析速度慢

**可能原因**：
- 网络连接不稳定
- 邮件内容过长
- API服务器繁忙

**解决方案**：
1. 检查网络连接
2. 尝试分析较短的邮件
3. 稍后重试
4. 更换模型（如从Pro换到Flash）

### 问题2：分析结果不准确

**可能原因**：
- 提示词不够明确
- 邮件内容格式特殊
- 使用的模型不适合

**解决方案**：
1. 优化提示词，更加具体
2. 尝试其他AI模型
3. 分段分析长邮件
4. 检查邮件是否完整显示

### 问题3：无法提取邮件内容

**可能原因**：
- Gmail DOM结构变化
- 邮件加载未完成
- 浏览器兼容性问题

**解决方案**：
1. 刷新Gmail页面
2. 等待邮件完全加载
3. 更新Chrome浏览器
4. 检查控制台错误（F12）
5. [提交Issue](https://github.com/chongyang1999/email_event/issues)

### 问题4：API额度耗尽

**症状**：
- 显示"Resource has been exhausted"错误
- 突然无法分析任何邮件

**解决方案**：
1. 访问 [AI Studio](https://aistudio.google.com) 检查配额
2. 等待配额重置（每日/每分钟）
3. 考虑升级到付费计划
4. 使用多个API Key轮换（注意遵守ToS）

### 问题5：特殊字符显示异常

**可能原因**：
- 编码问题
- 特殊语言字符

**解决方案**：
1. 通常AI能正确处理中文、日文等
2. 如果显示异常，尝试复制后重新粘贴
3. 提交问题时附带截图
